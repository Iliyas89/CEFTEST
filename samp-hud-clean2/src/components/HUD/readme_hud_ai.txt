================================================================================
ТЕХНИЧЕСКОЕ ЗАДАНИЕ: ИНТЕГРАЦИЯ CEF-HUD В ИГРОВОЙ МОД (PAWN + КЛИЕНТСКИЙ СКРИПТ)
================================================================================

ОБЩЕЕ ОПИСАНИЕ СИСТЕМЫ:
Мы интегрируем кастомный оверлей интерфейса (HUD), написанный на React (CEF).
Взаимодействие между игровой сессией и веб-интерфейсом происходит через единую 
глобальную функцию в браузере:
👉 window.updateHUD(dataJsonString);

Функция принимает строго ОДИН аргумент — строку в формате JSON. Интерфейс 
реактивный (useState), поэтому можно присылать как полный пакет данных, 
так и только изменившиеся ключи выборочно.

================================================================================
ЧАСТЬ 1: СПЕЦИФИКАЦИЯ ДАННЫХ (ФОРМАТ JSON)
================================================================================
Интерфейс ожидает JSON-объект со следующей структурой переменных:

{
  "health": 100,          // [Число] Здоровье игрока (0 - 100)
  "armor": 50,            // [Число] Броня игрока (0 - 100)
  "hunger": 80,           // [Число] Уровень голода/сытости (0 - 100)
  "money": 1500350,       // [Число] Баланс денег (Форматируется с пробелами внутри CEF)
  "playerId": 777,        // [Число] ID игрока на сервере (0 - 1000)
  "serverIndex": 1,       // [Число] Номер текущего сервера (1 - 10)
  "serverName": "TEST 1"  // [Строка] Название текущего сервера/подсервера
}

================================================================================
ЧАСТЬ 2: РАСПРЕДЕЛЕНИЕ ОБЯЗАННОСТЕЙ И СЕТЕВАЯ ОПТИМИЗАЦИЯ
================================================================================

ПРАВИЛО СИНХРОНИЗАЦИИ ХП/БРОНИ (КЛИЕНТСКАЯ ЧАСТЬ):
Чтобы избежать задержек (пинга) при отображении полученного игроком урона, 
показатели Health и Armor должны считываться и отправляться НАПРЯМУЮ КЛИЕНТОМ.

Обязанности клиентского скрипта (C++ / C# / JS плагин лаунчера):
1. Инициализация HUD: При успешном коннекте/спавне игрока создать CEF-браузер, 
   выставить ему размер на весь экран, pointer-events: none (пропуск кликов мыши), 
   и загрузить URL HUD-интерфейса.
2. Клиентский Таймер (Интервал: 500 - 1000 мс):
   Локально считывать из памяти игры текущее ХП персонажа (0.0 - 100.0) 
   и Броню (0.0 - 100.0). Если значения изменились по сравнению с прошлым тактом, 
   мгновенно выполнить вызов в CEF:
   `window.updateHUD('{"health": ' + currentHp + ', "armor": ' + currentArmor + '}');`

--------------------------------------------------------------------------------

ПРАВИЛО ИГРОВОЙ ЛОГИКИ (СЕРВЕРНАЯ ЧАСТЬ НА PAWN):
Все остальные переменные (Деньги, Голод, Данные сервера) являются критически 
важными. Сервер рассчитывает их внутри Pawn и отправляет пакеты изменений.

Обязанности серверного кода (Pawn):
1. Инициализация при авторизации (ОДНОКРАТНО):
   Как только игрок авторизовался (OnPlayerSpawn / OnPlayerLogin), сервер обязан 
   собрать стартовый пакет из базы данных (MySQL/ini) и отправить игроку:
   - ID игрока (GetPlayerID)
   - Деньги игрока (массив данных игрока, например PlayerInfo[playerid][pMoney])
   - Голод игрока (PlayerInfo[playerid][pHunger])
   - Константы сервера: номер и имя (например, #define SERVER_NAME "AVALON RP")
   Строка отправки (пример):
   `{"playerId": 5, "money": 250000, "hunger": 100, "serverIndex": 1, "serverName": "AVALON"}`

2. Переключение/События денег:
   При любых операциях с деньгами (покупка в магазине, зарплата, передача денег):
   - Изменить переменную в моде (GivePlayerMoneyCustom / PlayerInfo[playerid][pMoney])
   - Сразу после этого вызвать функцию отправки RPC в CEF: `{"money": NewMoneyValue}`

3. Системный Таймер Голода (Низкочастотный — раз в 1-2 минуты):
   - Пробегаться циклом по всем игрокам онлайн.
   - Снижать показатель `pHunger` на установленное значение.
   - Если сытость упала, отправлять пакет конкретному playerid: `{"hunger": NewHungerValue}`

4. Таймер Обновления Онлайна (Раз в 10-30 секунд):
   - Сервер подсчитывает общий онлайн (Iter_Count(Player) или GetMaxPlayers).
   - Отправляет пакет всем игрокам: `{"online": CurrentOnline}`
